# MISSION s01e02 — «Осмотреться»

**Тип:** `Type A` — Bash Automation
**Концепт:** `ls` — увидеть содержимое директории, включая скрытые файлы
**Оценка времени:** ~50 минут

---

## Задача

`pwd` сказал тебе, где ты. Теперь — что вокруг? LILITH говорила о трёх файлах,
но обычный `ls` показывает только `documents/`. Собери `look_around.sh` —
инструмент, который «включает весь свет»: показывает содержимое директории с
деталями И скрытыми файлами (те, что начинаются с точки).

**Артефакт:** `look_around.sh` (в корне серии). Старт — из `starter/`:

```bash
cp starter/look_around.sh ./look_around.sh
# отредактируй TODO, затем:
bash tests/test.sh
```

Скрипт принимает директорию аргументом (`./look_around.sh /path`), по умолчанию — текущую.

---

## Критерии приёмки

`bash tests/test.sh` зелёный (7 проверок). Ключевое:

1. Корректный bash-скрипт с shebang.
2. Показывает **скрытые** файлы (`.secret_location`, `.next_server`) — значит,
   использует `ls -a`/`ls -la`, а не обычный `ls`.
3. Показывает и обычные файлы.
4. В тесте есть самопроверка: наивный `ls` (без `-a`) её не проходит.

| Требование | Значение |
