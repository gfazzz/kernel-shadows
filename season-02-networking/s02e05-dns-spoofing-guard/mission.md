**Концепт:** обнаружение DNS-спуфинга — сверка резолва с эталоном
**Оценка времени:** ~55 минут

---

## Задача

Крылов травит DNS-кэш: подменяет ответы, и `shadow-05` резолвится в его сервер вместо
нашего. `dig` вернёт «нормальный» IP — но не тот. Собери капстоун `dns_guard.sh`: по
baseline (домен → известный правильный IP) резолвит каждый и ловит расхождения.

**Артефакт:** `dns_guard.sh` (в artifacts/).
Использование: `./dns_guard.sh baseline.txt` (строки `домен ожидаемый_IP`).

```bash
cp starter/dns_guard.sh artifacts/dns_guard.sh
# отредактируй TODO, затем:
bash tests/test.sh
```

---

## Критерии приёмки

`bash tests/test.sh` зелёный (8 проверок). Ключевое:

1. Корректный bash-скрипт с shebang.
2. Резолвит каждый домен baseline через `dig … A +short` (первая строка).
3. Сравнивает с эталоном: совпало → `✓`, иначе → `⚠️ ВОЗМОЖНА ПОДМЕНА`.
4. Итог `OK=N SPOOFED=M`; при `SPOOFED>0` — `ALERT` в stderr.
5. Отсутствующий baseline → ненулевой exit.

> Тест **мокает `dig`**: `shadow-05` «отравлен» (IP Крылова) — ждём обнаружение.
