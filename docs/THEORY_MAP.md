# Карта зависимостей концептов

Правило курса: **концепт X можно использовать в зачётном коде серии N, только
если X введён в серии ≤ N.** Исключение — осознанный предпросмотр: тогда в
тексте стоит пометка «разберём в sNNeMM», и X не попадает в то, что проверяет
тест.

Правило распространяется и на инструменты (`tar`, `curl`, `python3`, `gcc`,
`make`): `tools/check_tools.sh` проверяет это механически, `make tools`
запускает проверку.

---

## Указатель концептов по сериям

Полный указатель генерируется из шапок серий, а не пишется руками:

```bash
bash tools/gen_index.sh      # -> docs/CURRICULUM.md
```

Дублировать его здесь значило бы завести второй источник правды, который
разойдётся с первым.

## Сквозные линии

То, чего генератор не даёт: темы, которые вводятся один раз и потом
возвращаются в другом качестве. По ним проверяют, что новая серия не забегает
вперёд и не повторяет пройденное.

| Линия | Введена | Возвращается |
|---|---|---|
| текст: `grep`, `awk`, `sed`, конвейеры | s01e10–s01e12 | везде, где разбирают снимок; предел — `s08e06` (нужен Python) |
| права и `sudo` | s01e15–s01e16 | `s03e01`–`s03e03` (углубление), `s08e05` (`NOPASSWD` как находка) |
| сокеты и порты | s02e02 | `s07e08` (очередь принятия), `s08e01` (SYN), `s08e11` (`/proc/net/tcp`) |
| default-deny | s02e06–s02e07 | `s05e11` (укрепление), `s08e10` (ордер) |
| SSH: ключи и укрепление | s02e08–s02e09 | `s08e05` (`authorized_keys` как закрепление), `s08e09` (общий ключ) |
| systemd | s03e05–s03e06 | `s08e05` (юнит как закрепление), `s08e12` (фаза приёмки) |
| журнал как источник | s03e07 | `s05e08` (`auditd`), `s08e06` (хронология), `s07e11` (чего в журнале нет) |
| идемпотентность | s04e10–s04e12 | `s08e08` (очистка как состояние) |
| образы и отпечатки | s04e04–s04e05 | `s07e02` (ссылка по отпечатку), `s08e07` (цепочка поставок) |
| разбор снятого состояния | s05e09 | весь S7 и S8: живой системе верить нельзя |
| контроль целостности | s05e08 | `s08e05` (эталон), `s08e11` (перекрёстный взгляд) |
| Python там, где кончается bash | s06e10 | `s07e09`, `s08e03`, `s08e06`, `s08e12` |
| модуль ядра | s06e11–s06e12 | `s08e11` (руткит как модуль) |
| измерение до изменения | s07e08–s07e10 | `s08e01` (какой ресурс исчерпан) |
| свойство вместо константы | сквозное правило курса | тесты всего курса; тема капстоуна `s08e12` |

## Справочники — в одном месте

Повторяющиеся справочные блоки живут в [`RESOURCES.md`](RESOURCES.md), а серии
на них ссылаются. Библиография собирается из `theory.md` всех серий:

```bash
bash tools/gen_bibliography.sh   # -> docs/RESOURCES.md
```
