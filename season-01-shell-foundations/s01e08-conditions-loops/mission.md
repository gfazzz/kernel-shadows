## Обстановка

Проверка одного узла есть. Узлов пятьдесят, и проверять их надо каждые пять минут.
Ручной прогон превращается в ритуал: к тринадцатому запуску внимание отключается,
и мёртвый сервер проходит мимо взгляда.

Список лежит в файле. Реальный список — с комментариями и пустыми строками:
кто-то пометил плановые работы, кто-то оставил заметку на будущее.

## Приказ

Собрать `check_all.sh` — читает файл со списком, проверяет каждый узел и выводит
итог:

```
[UP]   shadow-server-01
[DOWN] shadow-server-09
---
ИТОГО: UP=3 DOWN=2
```

Имя узла — первое поле строки. Пустые строки и строки, начинающиеся с `#`,
пропускаются.

## Данные

| Что | Как |
|---|---|
| чтение файла | `while IFS= read -r line; do … done < "$list"` |
| пропуск пустых | `[ -z "$line" ] && continue` |
| пропуск комментариев | `case "$line" in \#*) continue ;; esac` |
| имя из строки | `host="${line%% *}"` — без `awk`, он появится в s01e11 |
| решение | `if ping -c 1 -W 2 "$host" >/dev/null 2>&1; then … else … fi` |
| счётчики | `up=$((up + 1))`, объявить до цикла |

## Критерии приёмки

- [ ] `artifacts/check_all.sh` создан, есть shebang, `bash -n` без ошибок.
- [ ] Файл читается через `while IFS= read -r`, а не `for … $(cat …)`.
- [ ] Пустые строки и комментарии пропускаются.
- [ ] Для каждого узла печатается строка со статусом.
- [ ] Итог `UP=<n> DOWN=<m>` соответствует реальным результатам.
- [ ] Счётчики не теряются (цикл не в подоболочке).
- [ ] Отсутствующий файл → сообщение в stderr и ненулевой код возврата.
- [ ] `bash tests/test.sh` → 9 passed, 0 failed.

## Требования среды

| Требование | Значение |
|---|---|
| root / sudo | не нужен |
| ОС | любая с bash (Linux / macOS / WSL) |
| Сеть | **не нужна** — тест подменяет `ping` |
| systemd / Docker / k8s | не нужны |
| Внешние пакеты | в реальном запуске `ping`; в тесте заменяется |
| Изоляция теста | мок-`ping` + фикстура-список во временном каталоге |

Фикстура теста: три доступных узла, два молчащих, плюс комментарий и пустая
строка. Ожидаемый итог — `UP=3 DOWN=2`.

## Выполнение

```bash
cp starter/check_all.sh artifacts/check_all.sh
# заменить TODO
bash artifacts/check_all.sh ../data/servers.txt   # реальный список для практики
bash tests/test.sh
```

Реальные адреса из `data/servers.txt` требуют сети и могут не отвечать —
это нормально: тест работает на заглушке.

## Диагностика

| Симптом | Причина | Что делать |
|---|---|---|
| `UP=0 DOWN=0` при верных строках вывода | цикл в подоболочке (`cat \| while`) | читать через `done < "$list"` |
| в отчёте попал `#` или пустая строка | нет фильтров | добавить `continue` для пустых и комментариев |
| пингуется вся строка целиком | не выделено первое поле | `host="${line%% *}"` |
| считает на один больше | последняя строка без перевода строки | `read` вернёт её, но с ненулевым кодом — цикл всё равно обработает; проверить фильтры |
| нет файла → `UP=0 DOWN=0` | отсутствие проверки входа | `[ -f "$list" ]` до цикла, иначе `exit 1` |

## После выполнения

Если тест зелёный — пятьдесят машин проверяются одним запуском, а мусор в списке
не портит статистику. Дмитрий получит картину целиком, а не выборку из первых
двенадцати строк.

Если итог не сходится с выводом — почти наверняка цикл ушёл в подоболочку. Это
самая частая ошибка в bash-скриптах и самая обидная: строки печатаются верно,
счётчики врут, а искать начинают в арифметике. Ошибка почти никогда не там,
куда смотришь.
