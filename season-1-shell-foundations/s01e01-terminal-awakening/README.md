## Теория: `pwd` — твой GPS (один концепт)

Представь: ты проснулся в незнакомом здании. Темно, нет окон. Где ты? В реальной жизни достаёшь телефон, смотришь GPS: *«ТЦ Мега, 3-й этаж»*.

**В Linux твой GPS — команда `pwd`** (**P**rint **W**orking **D**irectory).

```bash
pwd
```

Всё. Без флагов. Она печатает **абсолютный путь** — от корня файловой системы `/` до того места, где ты стоишь:

```console
$ pwd
/home/max/kernel-shadows/season-1-shell-foundations/s01e01-terminal-awakening
```

Linux — это **одно дерево** с корнем `/` (не `C:`, `D:`, как в Windows). Дом пользователя — ветка `/home/max`, у неё есть короткое имя `~`. Подробнее про дерево, абсолютные/относительные пути и тонкость `pwd -P` vs `pwd -L` — в [`theory.md`](theory.md).

> **LILITH:** *«Путь не врёт. Логи не врут. Люди — врут. `pwd` — первая команда на чужом сервере. Всегда.»*

Почему это важно на практике: `.bashrc` мог сделать `cd`, скрипт мог сменить директорию, предыдущий админ оставил сессию в `/var/log`. Профи не угадывает — он проверяет.

## Проверка «в мире сюжета»

**LILITH:** *«Два сисадмина подключились к серверу. Один сразу набрал `pwd`, второй — нет. Кто опытнее и почему?»*

<details>
<summary>Подумай 30 секунд</summary>

Первый. Опытный **рефлекторно** проверяет, где он, перед любыми действиями. Новичок думает «я же только подключился, я дома» — и ошибается, если `.bashrc`/скрипт/чужая сессия увели его в другое место. Правило: **не угадывай, проверь.**

> **LILITH:** *«Предположения убивают серверы. Факты спасают. `pwd` — это факт.»*
</details>

**LILITH:** *«Что печатает `pwd` — абсолютный путь или относительный? И почему именно такой надёжен?»*

<details>
<summary>Ответ</summary>

Абсолютный (начинается с `/`). Он однозначен из любой точки дерева — в отличие от относительного `ops`, который зависит от того, где ты сейчас.
</details>

## Задача

Собери свой первый инструмент — **`whereami.sh`**. Он должен одной командой отвечать: где я сейчас, где мой дом, и в корне ли я. Это `Type A` (Bash Automation): маленький скрипт-обёртка, чтобы повторять ориентацию одной командой.

```bash
# 1. взять каркас
cp starter/whereami.sh ./whereami.sh

# 2. заменить TODO своим кодом (подсказка: команда из 3 букв)

# 3. проверить — воспроизводимый тест на фикстуре, без root
bash tests/test.sh
```

Полное ТЗ, критерии приёмки и блок «Требования среды» — в [`mission.md`](mission.md). Тест зелёный «из коробки» на эталоне; как только создашь свой `whereami.sh`, он проверит именно твоё решение (6 проверок, в т.ч. что путь не захардкожен).

<details>
<summary>Подсказка (если застрял 5+ минут)</summary>

```bash
here="$(pwd)"
echo "Текущая директория: ${here}"
echo "Домашняя директория: ${HOME}"
```

Дальше добавь проверку `if [ "${here}" = "/" ]; then ... fi`. Эталон — в `solution/`, но открывай его **после** своей попытки.
</details>
