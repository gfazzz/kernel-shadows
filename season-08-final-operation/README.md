## О чём сезон

Четыре дня. «Новая Эра» бьёт по всей инфраструктуре сразу, и защищать её
приходится тем, что построено за предыдущие пятьдесят шесть.

День первый — наплыв: гигабит трафика при живом канале и лежащем приложении.
Диагноз ставится не по громкости, а по тому, какой ресурс исчерпан. Дальше
уязвимость без патча, для которой нужна мера со сроком снятия, и восемь мест,
где закрепляются в Linux.

День второй — разбор: пять форматов времени, сведённых к одной оси; образ,
которому верили; очистка, доказанная вторым прогоном. День третий —
контрнаступление в границах ордера, а не «ответить тем же». День четвёртый —
руткит, которого нельзя спросить изнутри, и приёмка.

**Подсказок нет.** В `starter/` только договор вызова и приёмочные сцены.
Подзадачи и критерии формулируешь сам — как это и происходит на реальном
инциденте.

## Сквозной артефакт: `shadow_core`

Финал не строит новый артефакт — он **принимает** всё построенное.
`shadow_core` (`s08e12`) прогоняет двенадцать фаз, каждая подтверждает навык
своего сезона измеримым свойством:

```
S1 инструментарий      S5 счёт CIS-контролей
S2 SSH без пароля      S6 узел /dev/shadow0 отвечает
S3 служба в песочнице  S7 бюджет ошибок не превышен
S4 идемпотентность     S8 закрепление снято, ордер соблюдён,
                          расхождений нет, узлы в строю
```

Курс, начавшийся с `pwd`, заканчивается программой, которая проверяемо
отвечает на тот же вопрос — «в каком мы состоянии» — про всю инфраструктуру.
Не поздравлением, а прогоном, который возвращает ноль или не возвращает.

## Как проходить

```bash
cd s08e01-first-wave
less README.md                 # сцена, теория, задание
cp starter/* artifacts/        # каркас с TODO
bash tests/test.sh             # красный — так и задумано
```

Тест здесь не судья, а спецификация: его вывод говорит, чего не хватает.
Зелёным он станет, когда задание выполнено. `solution/` открывай после
своей попытки, а не вместо неё.

Курс проходят в режиме **`Ask`**, а не `Agent` — иначе помощник решит серию
за тебя. Подробнее — в [корневом README](../README.md#ask-а-не-agent).

## Что ломается в этом сезоне

| Симптом | Настоящая причина | Где |
|---|---|---|
| гигабит трафика, приложение лежит | исчерпана очередь, не полоса | `s08e01` |
| очередь переполнена | состояние хранится до рукопожатия | `s08e02` |
| канал под сотню гигабит | фильтровать поздно, нужен blackhole | `s08e03` |
| RCE, патча нет три дня | нужна мера со сроком, не отключение | `s08e04` |
| процессы пережили перезагрузку | закрепление в одном из восьми мест | `s08e05` |
| «когда вошли» неизвестно | пять форматов времени не сведены | `s08e06` |
| ключ появился без события | приехал с образом | `s08e07` |
| «я всё удалил» | удалил ≠ удалено | `s08e08` |
| пять доводов против человека | журнал знает предмет, не человека | `s08e09` |
| «ответить тем же» | вне ордера, и технически не работает | `s08e10` |
| узел занят, проверки чисты | руткит врёт изнутри | `s08e11` |
| «мы выстояли» | нужна приёмка, а не слова | `s08e12` |
