## Теория: `ping` + `traceroute` (один концепт: диагностика пути)

**`ping`** шлёт ICMP Echo и ждёт ответ:

```bash
ping -c 1 -W 2 8.8.8.8
# 64 bytes from 8.8.8.8: icmp_seq=0 ttl=57 time=12.3 ms
```

Из вывода важны `time=` (RTT — задержка) и `packet loss` (потери). Рост RTT и потери — перегрузка или DDoS. Exit code даёт «жив/нет», но помни: хост может блокировать ICMP.

**`traceroute`** показывает путь по хопам (роутерам) — где обрывается путь, там и проблема. Детали ICMP, TTL, `ip route`, `tcpdump` — в [`theory.md`](theory.md).

> **LILITH:** *«Каждый пакет рассказывает историю. `time=` — как далеко и как быстро. Потери — что-то не так. Научись слушать пакеты — и сеть перестанет быть чёрным ящиком.»*

## Проверка «в мире сюжета»

**Дмитрий:** *«`ping` вернул 0% loss, но `time` вырос со 12 до 400 мс. Хост „мёртв"?»*

<details>
<summary>Подумай 30 секунд</summary>

Нет — хост жив (потерь нет), но путь до него **перегружен**: задержка выросла в 30 раз. Это ранний признак проблемы (DDoS, забитый канал, кривой маршрут). Поэтому в аудите важен не только UP/DOWN, но и RTT — он ловит деградацию до того, как хост «упадёт».
</details>

**Анна:** *«Зачем `traceroute`, если `ping` уже сказал „недоступен"?»*

<details>
<summary>Ответ</summary>

`ping` говорит «дошло/нет», но не «где потерялось». `traceroute` показывает цепочку роутеров: если пакет доходит до хопа 8 и дальше тишина — проблема между хопом 8 и целью (обрыв, firewall, «чёрная дыра»), а не у тебя. Это сужает поиск с «вся сеть» до «конкретный участок».
</details>

## Задача (капстоун ep05)

Собери `net_diag.sh`: по списку хостов пингует каждый, парсит RTT из вывода и печатает таблицу `HOST / STATUS / RTT` + итог. Здесь соединяются адресация → порты → диагностика в аудит сети.

```bash
cp starter/net_diag.sh ./net_diag.sh
# заменить TODO (ping + $? + sed по time=)
bash tests/test.sh
```

ТЗ и «Требования среды» — в [`mission.md`](mission.md). Тест (8 проверок) мокает `ping` (доступные отвечают `time=12.3 ms`): ждём разбор RTT, статусы и `UP=2 DOWN=1`.

<details>
<summary>Подсказка (после попытки)</summary>

```bash
out="$(ping -c 1 -W 2 "$host" 2>/dev/null)"
if [ $? -eq 0 ]; then
    rtt="$(printf '%s' "$out" | sed -n 's/.*time=\([0-9.]*\).*/\1/p' | head -1)"
fi
```

Эталон — в `solution/`, открывай после своей попытки.
</details>
