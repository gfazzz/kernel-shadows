# data/ — учебные данные Season 2

Реальные данные-пропсы для практики (отдельно от автотестов — тесты серий
самодостаточны и мокают сетевые команды). Сохранено из оригинальных эпизодов при
рефакторинге v2.0, чтобы ничего ценного не потерялось.

## Что где

| Файл | Для серий | Что это |
|------|-----------|---------|
| `network_map.txt` | s02e01–s02e03 | карта сети ЦОД «Москва-1» (адреса/подсети) — практика адресации и диагностики. |
| `allowed_ports.txt` | s02e02 | согласованный allowlist слушающих TCP-портов операции. |
| `ss_listen_moscow1.txt` | s02e02 | снятый на сервере вывод `ss -tuln` — **объект разведки** серии (Type C). |
| `ufw_status_moscow1.txt` | s02e06 | снятый вывод `ufw status verbose` — **объект разведки** серии (Type C). |
| `dns_zones.txt` | s02e04–s02e05 | примеры DNS-зон/записей для разбора `dig`. |
| `suspicious_domains.txt` | s02e05 | подозрительные/отравленные домены (следы Крылова) — для детекта спуфинга. |
| `botnet_ips.txt` | s02e06–s02e07 | реальный список IP ботнета (Tor exit nodes + атака) — для `block_botnet.sh`. |

## Как пользоваться

```bash
cd season-02-networking
# сгенерировать правила блокировки по реальному списку ботнета
./s02e07-block-botnet/solution/block_botnet.sh data/botnet_ips.txt /tmp/block_rules.sh

# разобрать адреса из карты сети
grep -oE '([0-9]+\.){3}[0-9]+' data/network_map.txt | while read ip; do
    ./s02e01-tcpip-addressing/solution/ipinfo.sh "$ip"
done
```

> Реальные сетевые команды (`ping`, `dig`, `ufw`) требуют сети/root и могут быть
> заблокированы — это нормально. Автотесты серий сеть/root не используют (мокают).
