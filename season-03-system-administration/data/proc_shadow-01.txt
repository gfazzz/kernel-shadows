# Снимок /proc по четырём процессам shadow-server-01
# Снят 17 октября в 07:44, следом за таблицей процессов.
#
# Команда (для каждого PID):
#   ls -l /proc/PID/exe /proc/PID/cwd
#   tr '\0' ' ' < /proc/PID/cmdline; echo
#   grep -E '^(Name|State|PPid|Uid|Gid|Threads):' /proc/PID/status
#   ls -l /proc/PID/fd
#
# Зачем это нужно, если есть ps: строку COMMAND в выводе ps процесс задаёт
# сам — она берётся из его же /proc/PID/cmdline и переписывается изнутри
# одним присваиванием argv[0]. А символьная ссылка /proc/PID/exe ведёт на
# файл, который ядро действительно загрузило, и подделать её процесс не может.
# Пометка «(deleted)» означает, что файл удалён с диска, а процесс с ним
# продолжает работать: содержимое живо, пока открыт дескриптор.
