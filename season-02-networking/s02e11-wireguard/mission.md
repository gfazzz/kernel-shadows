## Обстановка

Туннели из [`s02e10`](../s02e10-ssh-tunnels/) живут, пока открыта сессия.
Завтра команда работает из трёх городов, и нужен не отдельный порт,
а сеть — которая переживёт смену Wi-Fi и закрытую крышку ноутбука.

Дмитрий поднял VPN за вечер и раздал всем один конфиг, поменяв только адрес.
Соединение устанавливается, до шлюза трафик идёт. До Анны — нет.

## Приказ

Переписать `artifacts/wg0.conf` — конфигурацию вашего узла.

```bash
cp starter/wg0.conf artifacts/wg0.conf
bash tests/test.sh
```

## Схема

```
             интернет
                 │
   вы  10.77.0.4 ├── шлюз 10.77.0.1  ──►  сеть операции 10.50.0.0/16
     (за NAT)    │   (белый адрес, vpn.ops.example:51820)
                 │
                 └── Анна 10.77.0.5
                     (тоже за NAT)
```

| Что | Значение |
|---|---|
| ваш адрес в VPN | `10.77.0.4` |
| приватный ключ | из стартера |
| внутренний DNS | `10.50.0.53` |
| шлюз: публичный ключ | `Vkxt97L+ElJY4+u1Vw3mXOwAcqfBWawRG9u6g+FoqBA=` |
| шлюз: endpoint | `vpn.ops.example:51820` |
| Анна: публичный ключ | `sGA0Im1LFnYLXyTXTd8n/RH4PW1GzNdZOzLpXfxDhuo=` |

## Требования

| Что | Зачем |
|---|---|
| `AllowedIPs` пиров **не пересекаются** | иначе первый подошедший забирает весь трафик |
| через шлюз — сеть операции, не `0.0.0.0/0` | почта и браузер должны идти обычным путём |
| до Анны — только её адрес | прямой канал, а не всё подряд |
| `Address` с маской `/32` | сеть описывается пирами, а не маской интерфейса |
| `PersistentKeepalive` | вы за NAT: запись в трансляции живёт 30–120 с |
| `Endpoint` только у шлюза | Анна за NAT, её адрес узнается из первого пакета |
| `DNS` задан | иначе `db.internal` не разрешится |
| `ListenPort` не задан | фиксированный порт нужен только тому, к кому приходят |

## Чем добывать

| Что нужно | Как |
|---|---|
| свой адрес и ключ | секция `[Interface]`: `Address`, `PrivateKey` |
| резолвер | `DNS = 10.50.0.53` |
| пир | секция `[Peer]`: `PublicKey`, `AllowedIPs` |
| куда стучаться | `Endpoint = хост:порт` |
| держать NAT открытым | `PersistentKeepalive = 25` |
| проверить на своей машине | `wg show`, `ip route show dev wg0` |

Несколько подсетей в `AllowedIPs` перечисляются через запятую.

## Критерии приёмки

- [ ] `artifacts/wg0.conf` создан на основе `starter/`, все строки — секции или «ключ = значение».
- [ ] Ровно одна секция `[Interface]` и не меньше двух `[Peer]`.
- [ ] `Address` — приватный адрес с маской `/32`.
- [ ] `PrivateKey` на месте, `DNS` задан, `ListenPort` не задан.
- [ ] У каждого пира есть `PublicKey` и `AllowedIPs`; ключи различны.
- [ ] **`AllowedIPs` пиров не пересекаются.**
- [ ] Через шлюз маршрутизируется `10.50.0.0/16`; `0.0.0.0/0` не используется.
- [ ] `Endpoint` с портом — только у шлюза; второй пир без него.
- [ ] `PersistentKeepalive` задан у обоих пиров в пределах 10–30.
- [ ] `bash tests/test.sh` → 19 passed, 0 failed.


Если WireGuard есть на вашей машине, стоит посмотреть, как выглядит правда

```bash
sudo wg show          # рукопожатия и счётчики — единственное, чему стоит верить

```

## Диагностика

| Симптом | Причина | Что делать |
|---|---|---|
| «AllowedIPs пересекаются» | у двух пиров общие адреса | развести: сеть операции шлюзу, `/32` — Анне |
| «не включает сеть операции» | оставлен `0.0.0.0/0` | перечислить нужные подсети явно |
| «маска не /32» | скопировано `/24` | сеть задают пиры, а не интерфейс |
| «PersistentKeepalive» | не задан | вы за NAT: 25 секунд |
| «ListenPort задан» | скопировано с сервера | инициирующему узлу порт не нужен |
| «Endpoint без порта» | указано только имя | `хост:51820` |
| «DNS не задан» | забыт | имена из `s02e04` иначе не разрешатся |
| рукопожатие есть, трафик нулевой | маршрутизация | смотреть `AllowedIPs` и `ip route` |

## После выполнения

Зелёный тест означает, что каждый адрес в вашей сети однозначно закреплён
за одним ключом. Это и есть весь WireGuard: таблица «какие адреса за каким
ключом», из которой следует и маршрутизация, и права доступа.

Стоит сравнить с предыдущей серией. Туннель `ssh` живёт, пока открыта
сессия, и переезд в другую сеть его рвёт. Здесь состояния соединения нет
вовсе: следующий пакет уйдёт с нового адреса, и пир примет его, потому что
подпись верна.

## Кумулятивность

Адреса и подсети читаются по [`s02e01`](../s02e01-tcpip-addressing/) —
`10.50.0.0/16` и `/32` оттуда. Внутренний DNS и разрешение имён вроде
`db.internal` — [`s02e04`](../s02e04-dns-lookup/). UDP-порт `51820`, который
надо открыть на шлюзе, — правило вида из
[`s02e06`](../s02e06-firewall-ufw/), и именно UDP, а не TCP. Ключевая пара
и то, что приватный ключ не покидает машину, — из
[`s02e08`](../s02e08-ssh-keys/); права `600` на файле с ключом — из
[`s01e15`](../../season-01-shell-foundations/s01e15-permissions-basics/).
Туннели, которые эта серия заменяет, — [`s02e10`](../s02e10-ssh-tunnels/).
