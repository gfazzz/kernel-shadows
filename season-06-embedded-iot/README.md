## О чём сезон

Тот же Linux, но без монитора, без администратора рядом и с питанием, которое
выдёргивают. Season 6 — про узлы, которые ставят и уезжают.

Шэньчжэнь, Хуацянбэй: плата без наклейки, о которой надо не догадаться, а
спросить её саму. Дальше ножки платы, загрузка, корень только для чтения —
и первая карта памяти, которая умирает не от брака, а от `atime`.

Вторая половина — дрон, который вернулся сам, хотя никто ничего не нажимал,
и сеть, в которой все говорят вслух: MQTT, `retained`-сообщения мёртвого узла
и брокер, где TLS настроен, а порт 1883 оставили «на миграцию».

Здесь впервые появляется **Type D**: до сих пор ты писал скрипты и правил
конфигурации, дальше — программа. Сначала на Python, потом модуль ядра и
символьное устройство на C.

## Сквозной артефакт: `shadow_mesh`

Сеть наблюдения собирается по сериям и к финалу существует целиком:

```
плата (s06e01–s06e04) ──▶ датчики по i2c/spi/1-wire
        │                        │
        │                   клиент-датчик (s06e10)
        │                        │
        ▼                        ▼
    /dev/shadow0          брокер MQTT с TLS и ACL (s06e08–s06e09)
  (s06e11–s06e12)                │
                                 ▼
              дрон с проверенным планом и failsafe (s06e05–s06e07)
```

Узлы `shadow_mesh` сдают телеметрию в `aurora` — контур эксплуатации
следующего сезона.

## Как проходить

```bash
cd s06e01-board-recon
less README.md                 # сцена, теория, задание
cp starter/* artifacts/        # каркас с TODO
bash tests/test.sh             # красный — так и задумано
```

Тест здесь не судья, а спецификация: его вывод говорит, чего не хватает.
Зелёным он станет, когда задание выполнено. `solution/` открывай после
своей попытки, а не вместо неё.

Курс проходят в режиме **`Ask`**, а не `Agent` — иначе помощник решит серию
за тебя. Подробнее — в [корневом README](../README.md#ask-а-не-agent).

## Что ломается в этом сезоне

Сезон построен вокруг ошибок, которые **выглядят как исправная работа**:

| Находка | Почему её не видно |
|---|---|
| `Exec format error` | права на месте, файл на месте — не совпадает архитектура |
| датчик молчит | узел шины выключен в дереве устройств, паяльник ни при чём |
| карта умирает за полгода | запись изнашивает ячейки; `atime` пишет при каждом **чтении** |
| дрон вернулся сам | никто не нажимал: сработал failsafe по потере навигации |
| `85.0 °C` в телеметрии | значение проходит CRC и выглядит настоящим |
| панель показывает `online` | брокер отдаёт `retained` мёртвого узла третьи сутки |
| узлы «мигают» | два устройства с одним `client_id` выбивают друг друга |
| конфигурация «защищена» | TLS настроен, но порт 1883 оставлен «на миграцию» |
| `cat /dev/shadow0` не кончается | драйвер не возвращает ноль в конце |

Общее у всех: **система не сообщает об ошибке.** Она работает, отвечает и
выглядит правильно — а неверна. Отсюда способ проверки, принятый в сезоне:
не «запустилось ли», а «что именно из этого следует».
