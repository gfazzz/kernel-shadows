## Теория: обнаружение спуфинга (один концепт: сверка с эталоном)

**Cache poisoning:** фальшивый ответ оседает в кэше резолвера на TTL и подменяет реальный IP. Один отравленный резолвер = тысячи жертв (amplification).

Простая и надёжная защита для своей инфраструктуры — **baseline-сверка**: держим список «домен → правильный IP» и сравниваем с текущим резолвом.

```bash
actual="$(dig "$domain" A +short | head -1)"
[ "$actual" = "$expected" ] || echo "⚠️ подмена: $actual вместо $expected"
```

Другие методы (несколько резолверов, DNSSEC, DNS over TLS, проверка `/etc/hosts`) — в [`theory.md`](theory.md).

> **LILITH:** *«Одна строка в `/etc/hosts` или отравленный кэш — и `bank.example` ведёт к Крылову. Не верь ответу — сверяй с тем, что знаешь наверняка.»*

## Проверка «в мире сюжета»

**Анна:** *«`dig` вернул IP из Tor-сети для нашего внутреннего сервера. Это точно атака?»*

<details>
<summary>Подумай 30 секунд</summary>

Внутренний сервер (`10.50.x` private) не может легитимно резолвиться в публичный Tor-адрес — это явный признак подмены: кто-то отравил кэш или `/etc/hosts`. Baseline-сверка ловит именно такие «невозможные» ответы: ожидали private, получили чужой public.
</details>

**Katarina** (криптограф из Стокгольмского университета, эксперт по DNS over TLS): *«Baseline-сверка ловит подмену. Но почему этого мало против всех атак?»*

<details>
<summary>Ответ</summary>

Baseline знает только заранее известные домены с фиксированными IP; для динамических адресов (CDN, облака) эталон не построить. Там нужны криптографические гарантии. Как формулирует Катарина: **«DNSSEC — это подпись на письме (целостность). DoT — это конверт (приватность). Нужно и то, и другое.»** DNSSEC подписывает ответ (подделать нельзя), DoT/DoH шифрует канал к резолверу (подслушать нельзя). Baseline — первый рубеж, не единственный.
</details>

ТЗ и «Требования среды» — в [`mission.md`](mission.md). Тест (8 проверок) мокает `dig` так, что `shadow-05` «отравлен» (IP Крылова): ждём обнаружение, `OK=2 SPOOFED=1`, `ALERT`.

<details>
<summary>Подсказка (после попытки)</summary>

```bash
actual="$(dig "$domain" A +short 2>/dev/null | head -1)"
if [ "$actual" = "$expected" ]; then ok=$((ok+1)); else spoofed=$((spoofed+1)); fi
```

Эталон — в `solution/`, открывай после своей попытки.
</details>
