## Критерии приёмки

`bash tests/test.sh` зелёный (10 проверок). Отчёт содержит:

1. Всего запросов (`wc -l`) и уникальных IP (`awk | sort -u | wc -l`).
2. Первый/последний таймстамп с **`sed`**-очисткой скобок (`sed 's/[][]//g'`).
3. TOP-10 IP (`awk | sort | uniq -c | sort -rn | head`).
4. Распределение HTTP-статусов (`awk '{print $9}' | …`).
5. Сверку IP из базы угроз с логом (`FOUND` для найденных, отсутствующие — молча).
6. Сохранение в указанный файл отчёта.
