## Расшифровка `ls -l` — паспорт файла

```console
$ ls -l
total 12
drwxr-xr-x 2 max max 4096 Oct  2 18:30 documents
-rw-r--r-- 1 max max  156 Oct  2 18:25 notes.txt
-rwxr-xr-x 1 max max 2145 Oct  2 18:28 script.sh
```

```
-rw-r--r--  1  max  max   156  Oct 2 18:25  notes.txt
│└┬┘└┬┘└┬┘  │   │    │     │        │           └ имя
│ │  │  │   │   │    │     │        └ дата/время изменения
│ │  │  │   │   │    │     └ размер, байт
│ │  │  │   │   │    └ группа-владелец
│ │  │  │   │   └ пользователь-владелец
│ │  │  │   └ число жёстких ссылок
│ │  │  └ права others (все остальные)
│ │  └ права group (группа)
│ └ права owner (владелец)
└ тип: '-' файл, 'd' директория, 'l' симлинк
```

## Права rwx

```
rw-  r--  r--
│    │    └ others: read
│    └ group: read
└ owner: read + write
```

- `r` = read (4), `w` = write (2), `x` = execute (1).
- `-rw-------` (600) — только владелец читает/пишет. Так должны лежать SSH-ключи.
- `-rwxrwxrwx` (777) — все могут всё. На сервере это дыра; такие файлы ищут и чинят.

Частая ошибка: файл есть, но без `x` его не запустить —
`bash: ./script.sh: Permission denied`. Лечится `chmod +x script.sh`.
(Полноценно chmod/права — в Season 3; здесь только читаем вывод.)

## Скрытые файлы (dotfiles)

Правило Linux: имя, начинающееся с точки `.`, по умолчанию не показывается.
Это **не защита** — просто «не мозолит глаза». Любой с правом `r` прочитает
`.secret`. Для защиты — права (`chmod 600`) или шифрование (`gpg`).

```console
$ ls
documents
$ ls -a
.  ..  .next_server  .secret_location  documents
```

- `.` — текущая директория, `..` — родительская.
- `ls -A` — как `-a`, но без `.` и `..` (удобно для подсчёта).

Зачем прячут: конфиги (`.bashrc`, `.gitconfig`), секреты (`.ssh/`, `.env`),
кэши (`.cache/`). Атакующие тоже прячут — backdoor в `.hidden_shell`. Поэтому
на чужом сервере `ls -la` рефлекторно.

## Полезные флаги

```bash
ls -lh    # human-readable размеры (156K вместо 159744)
ls -lt    # сортировка по времени (свежие сверху)
ls -lS    # сортировка по размеру
ls -lR    # рекурсивно вглубь
```
