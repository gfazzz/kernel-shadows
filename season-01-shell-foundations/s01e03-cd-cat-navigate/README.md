## Теория: `cd` + `cat` (один концепт: дойти и прочитать)

**`cd`** (**C**hange **D**irectory) — телепортация по дереву. Мгновенно, в отличие от реального мира:

```bash
cd documents     # относительный путь: отсюда внутрь
cd ..            # на уровень вверх
cd ~             # домой
cd /             # в корень
cd -             # назад, где был
```

Дошёл — теперь **открой конверт**. **`cat`** выводит содержимое файла целиком:

```console
$ cd documents
$ cat briefing.txt
OPERATION KERNEL SHADOWS — BRIEFING #001
FROM: Viktor Petrov ...
```

`cat` — для маленьких файлов. Для больших есть `less` (листалка с поиском, выход по `q`), а `head`/`tail` показывают начало/конец. Полная таблица выбора и спец-телепорты (`../..`, пробелы в именах, абсолютный vs относительный) — в [`theory.md`](theory.md).

> **LILITH:** *«`cd` — твои ноги, `..` — шаг назад, `~` — домой, `/` — в начало. `cat` для быстрого просмотра, `less` когда файл большой, `tail -f` для логов в реальном времени.»*

## Проверка «в мире сюжета»

**LILITH:** *«Ты в `/home/max/projects/web/frontend/src`. Нужно быстро в `/etc/nginx`. Что быстрее: считать `../../../../..` или `cd /etc/nginx`?»*

<details>
<summary>Подумай 20 секунд</summary>

`cd /etc/nginx` — абсолютный путь однозначен из любого места. Считать точки `..` — долго и легко ошибиться. Относительные пути хороши для близких переходов, абсолютные — для «прыжков» через всё дерево.
</details>

**LILITH:** *«`cat` или `less` для файла лога на 200 000 строк? Почему?»*

<details>
<summary>Ответ</summary>

`less`. `cat` вывалит все 200k строк в терминал разом — прокрутить и найти нужное невозможно. `less` листает вперёд-назад и умеет поиск (`/шаблон`).
</details>
