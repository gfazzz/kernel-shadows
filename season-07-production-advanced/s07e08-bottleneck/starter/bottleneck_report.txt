# bottleneck_report.txt — где узкое место (СТАРТЕР)
#
# Метод USE: по каждому ресурсу три вопроса — насколько он занят
# (utilization), есть ли к нему очередь (saturation), были ли отказы
# (errors). Ресурс, у которого утилизация упёрлась в потолок, а очередь
# растёт, и есть узкое место. Остальные надо честно исключить.
#
# Источники — в data/:
#   vmstat.txt          процессор, очередь на выполнение, подкачка
#   iostat.txt          диск: занятость, очередь, ожидание
#   free.txt            память узла
#   nstat.txt           сетевой стек: повторы, переполнение очереди приёма
#   cadvisor.txt        контейнер: троттлинг и память
#   app_metrics.txt     перцентили приложения и пул соединений к базе
#   use_thresholds.txt  пороги, за которыми ресурс считается узким местом
#
# Формат: ключ=значение, без пробелов вокруг «=». Все величины — целые.
# Правь копию в artifacts/, потом проверяй:  bash tests/test.sh
