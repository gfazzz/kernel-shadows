# MISSION s01e07 — «Проверить все серверы»

**Тип:** `Type A` — Bash Automation
**Концепт:** условия (`if/then`) + циклы (`while read` по файлу)
**Оценка времени:** ~55 минут

---

## Задача

Один хост ты проверяешь. Но у Дмитрия список из 50. Собери `check_all.sh`:
читает файл со списком серверов (строка = «имя IP»), проходит по нему циклом,
пингует каждый, по условию помечает `UP`/`DOWN` и печатает итог (сколько каких).

**Артефакт:** `check_all.sh` (в artifacts/). Принимает путь к списку:
`./check_all.sh servers.txt`.

```bash
cp starter/check_all.sh artifacts/check_all.sh
# отредактируй TODO, затем:
bash tests/test.sh
```

---

## Критерии приёмки

`bash tests/test.sh` зелёный (9 проверок). Ключевое:

1. Корректный bash-скрипт с shebang.
2. Читает файл построчно золотым паттерном `while IFS= read -r line; do … done < файл`.
3. Пропускает пустые строки и комментарии (`#…`).
4. Берёт имя хоста как первое поле (`host="${line%% *}"`) — **без `awk`**.
5. По условию (`if ping …; then`) помечает `UP`/`DOWN` и считает итог (`UP=3 DOWN=2`).
6. Отсутствующий файл → сообщение в stderr и ненулевой exit.

> Тест мокает `ping` (`up-*` достижимы) — живая сеть не нужна.
