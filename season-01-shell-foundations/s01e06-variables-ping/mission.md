## Задача

Дмитрий дал реальную задачу: проверять доступность серверов. Начни с одного.
Собери `check_host.sh` — пингует хост, кладёт результат в переменные и печатает
статус (`UP`/`DOWN`) вместе с exit code.

**Артефакт:** `check_host.sh` (в artifacts/). Принимает хост аргументом:
`./check_host.sh shadow-server-01`.

```bash

# отредактируй TODO, затем:

```

---

## Критерии приёмки

`bash tests/test.sh` зелёный (8 проверок). Ключевое:

1. Корректный bash-скрипт с shebang.
2. Пингует хост и **сохраняет exit code в переменную** (`code=$?`).
3. Достижимый хост → `STATUS: UP` и `EXIT_CODE: 0`; недостижимый → `STATUS: DOWN`.
4. Статус **зависит** от результата ping (не захардкожен «всегда UP»).
5. Печатает имя хоста, взятое из аргумента `$1`.

> Тест **подменяет `ping` мок-версией** — живая сеть не нужна, результат
> детерминирован на любой машине (принцип mock-first, план §5.3).
