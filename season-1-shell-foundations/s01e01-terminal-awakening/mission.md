# MISSION s01e01 — «Где я?»

**Тип:** `Type A` — Bash Automation
**Концепт:** `pwd` — ориентация в дереве файловой системы
**Оценка времени:** ~45 минут

---

## Задача

Виктор дал тестовое задание, LILITH наблюдает. Прежде чем искать спрятанные
файлы, нужен рефлекс профи: **всегда знать, где ты находишься**. Собери свой
первый инструмент — `whereami.sh`, который одной командой отвечает на вопрос
«где я сейчас в дереве файловой системы?».

**Артефакт:** `whereami.sh` (в корне серии).
Старт — из `starter/whereami.sh`:

```bash
cp starter/whereami.sh ./whereami.sh
# отредактируй TODO, затем:
bash tests/test.sh
```

---

## Критерии приёмки

Скрипт принят, если `bash tests/test.sh` зелёный. Конкретно:

1. `whereami.sh` существует и является корректным bash-скриптом (`bash -n` без ошибок).
2. В первой строке — shebang (`#!/usr/bin/env bash`).
3. Скрипт **печатает текущий абсолютный путь**, полученный через `pwd`
   (а не захардкоженный текст).
4. Скрипт печатает домашнюю директорию (`$HOME`).
5. Из разных директорий вывод **разный** (путь не захардкожен).

> Проверка автоматическая и **воспроизводимая**: тест создаёт временную
> фикстуру и запускает твой скрипт в ней. Твой живой хост не затрагивается.

---

## Требования среды

| Требование | Значение |
|------------|----------|
| root / sudo | **не нужен** |
| ОС | любая с bash (Linux / macOS / WSL) |
| Сеть | не нужна |
| systemd / Docker / k8s | не нужны |
| Внешние пакеты | нет (только coreutils: `pwd`, `echo`, `grep`) |
| Изоляция теста | фикстура во временном `TEST_ROOT` (`mktemp`), удаляется автоматически |

Это **unit-уровень** теста из плана v2.0 (§5.3): зелёный без прав и без порчи
системы. Интеграционных требований у этой серии нет.
