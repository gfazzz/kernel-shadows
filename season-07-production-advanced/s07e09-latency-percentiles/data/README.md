# Три снимка одной гистограммы

| Файл | Что это |
|---|---|
| `base.txt` | как было до изменения |
| `regression.txt` | после изменения, задержка выросла по-настоящему |
| `noise.txt` | после изменения, «выросла» на восемь процентов — внутри одной корзины |

Все три сняты за одно и то же окно в один и тот же час суток, по двадцать
тысяч наблюдений. Границы корзин у всех одинаковые — иначе сравнивать было
бы нечего вовсе.

Третий файл и есть предмет серии. Девяносто пятый перцентиль там на восемь
процентов выше базового, и это **не** означает, что стало медленнее:
обе величины лежат внутри одной и той же корзины, а внутри корзины
`histogram_quantile` не измеряет, а угадывает.
