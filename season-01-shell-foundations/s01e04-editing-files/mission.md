## Обстановка

Разведданные добыты, но пока лежат мёртвым грузом в отчёте. Чтобы подключиться
к узлу в Цюрихе, агент связи нужно настроить: подставить параметры доступа,
включить шифрование, погасить отладочный лог, который пишет эти параметры
открытым текстом.

Файл правится **в терминале** — графического редактора на сервере нет и не будет.
Это первая серия, где ты не читаешь файл, а изменяешь его.

## Приказ

Привести `artifacts/agent.conf` в рабочее состояние: параметры доступа из
`.next_server`, `encryption = on` раскомментировано, `debug_log = false`.

Чем править — твоё дело: `nano`, `vim`, любой другой консольный редактор.
Тест смотрит на результат, а не на способ.

## Данные

| Директива | Что поставить | Откуда взять |
|---|---|---|
| `server` | адрес узла | `IP Address` в `.next_server` |
| `port` | порт SSH | `Port` |
| `user` | имя пользователя | `Username` |
| `encryption` | `on` | строка есть, но закомментирована — раскомментировать |
| `debug_log` | `false` | сейчас `true` — переключить |
| `timeout` | `30` | менять не нужно |

## Критерии приёмки

- [ ] Конфиг создан в рабочей папке: `artifacts/agent.conf`.
- [ ] `server`, `port`, `user` совпадают с `.next_server` (тест читает источник заново).
- [ ] Ни одного `CHANGE_ME` не осталось.
- [ ] `encryption = on` — активная строка, а не комментарий.
- [ ] `debug_log = false`.
- [ ] `timeout = 30` не изменён.
- [ ] Комментарии-пояснения сохранены (не менее трёх строк на `#`).
- [ ] Директивы не задвоены: правится строка, а не дописывается рядом.
- [ ] `bash tests/test.sh` → 10 passed, 0 failed.

## Требования среды

| Требование | Значение |
|---|---|
| root / sudo | не нужен |
| ОС | любая с bash (Linux / macOS / WSL) |
| Сеть | не нужна |
| systemd / Docker / k8s | не нужны |
| Внешние пакеты | консольный редактор: `nano` (обычно есть) или `vi`/`vim` |
| Источник значений | `season-01-shell-foundations/data/test_environment/.next_server` |

Если в системе нет `nano` — используй `vi`: он есть везде, где есть Unix.
Минимум команд — в README и `theory.md`.

## Выполнение

```bash
cp starter/agent.conf artifacts/agent.conf
nano artifacts/agent.conf        # либо: vim artifacts/agent.conf
grep -vE '^\s*#|^\s*$' artifacts/agent.conf   # посмотреть только активные строки
bash tests/test.sh
```

Застрял в `vim` — `Esc`, затем `:q!` выйдет без сохранения, файл не пострадает.
LILITH объяснит клавиши, но править будешь ты.

## Диагностика

| Симптом | Причина | Что делать |
|---|---|---|
| `остались плейсхолдеры CHANGE_ME` | значение не подставлено | вписать значение из `.next_server` |
| `директива encryption отсутствует или закомментирована` | не убрана `#` в начале строки | удалить `# ` перед `encryption` |
| `указано 'true', ожидалось 'false'` | `debug_log` не переключён | заменить значение в строке |
| значение верное, но тест видит старое | директива задвоена | оставить одну строку, лишнюю удалить |
| `комментарии вычищены` | удалены пояснения вместе с решётками | вернуть строки-комментарии |
| в `vim` печатаются не буквы, а пропадают строки | ты в командном режиме | `Esc`, `u` для отмены, `i` для ввода |

## После выполнения

Если тест зелёный — канал настроен: агент знает, куда подключаться, трафик шифруется,
параметры доступа не утекают в лог. Ты научился главному навыку администратора,
которым пользуются каждый день: менять конфигурацию системы на месте, без графики.

Если тест ругается на задвоенные директивы — открой файл ещё раз и посмотри глазами.
Конфиг, где один параметр задан дважды с разными значениями, ведёт себя непредсказуемо:
одна служба возьмёт первое вхождение, другая — последнее. Такие файлы отлаживают часами,
а причина всегда одна и та же — «дописал рядом вместо того, чтобы поправить».
