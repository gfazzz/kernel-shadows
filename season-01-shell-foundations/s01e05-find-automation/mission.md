# MISSION s01e05 — «Детектив и автоматизация» (капстоун ep01)

**Тип:** `Type A` — Bash Automation
**Концепт:** `find` (рекурсивный поиск) + первый bash-скрипт с отчётом
**Оценка времени:** ~60 минут

---

## Задача

Три файла руками ты уже нашёл. Но так не масштабируется: на 50 серверах файлы
разбросаны по десяткам директорий. Пусть ищет машина. Собери капстоун-скрипт
`find_files.sh`, который **сам** находит три файла рекурсивно (`find`), читает их
(`cat`) и сохраняет отчёт в `report.txt`.

**Артефакт:** `find_files.sh` (в artifacts/).

```bash
cp starter/find_files.sh artifacts/find_files.sh
# отредактируй TODO, затем:
bash tests/test.sh
```

Использование: `./find_files.sh [BASE_DIR] [REPORT_FILE]` (по умолчанию `.` и `report.txt`).

---

## Критерии приёмки

`bash tests/test.sh` зелёный (8 проверок). Ключевое:

1. Корректный bash-скрипт с shebang.
2. Использует `find` **рекурсивно** — находит даже глубоко вложенный `.next_server`.
3. Читает содержимое всех трёх файлов (`cat`).
4. Сохраняет отчёт в указанный файл (`report.txt`).
5. Самопроверка теста: «плоский» `cat *` без `find` не проходит.
