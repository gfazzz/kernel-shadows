## Задача

Ботнет Крылова — 847 IP — лупит по серверу. Блокировать руками по одному нереально.
Собери капстоун `block_botnet.sh`: из списка IP **генерирует** скрипт с правилами
`ufw deny from <ip>` (не применяя их — применение требует root).

**Артефакт:** `block_botnet.sh` (в корне серии).
Использование: `./block_botnet.sh botnet_ips.txt block_rules.sh`.

```bash
cp starter/block_botnet.sh ./block_botnet.sh
# отредактируй TODO, затем:
bash tests/test.sh
```

> Реальные адреса ботнета есть в `../data/botnet_ips.txt` (после уборки сезона) —
> прогони на них для практики. Тест использует свою фикстуру.

---

## Критерии приёмки

`bash tests/test.sh` зелёный (9 проверок). Ключевое:

1. Корректный bash-скрипт с shebang.
2. На каждый IP из списка генерирует `ufw deny from <ip>`.
3. Пропускает комментарии (`#`) и пустые строки; отсекает inline-комментарии.
4. Сгенерированный файл — **валидный bash** (`bash -n`).
5. Сводка о числе правил; пустой список валидных IP → ненулевой exit.
