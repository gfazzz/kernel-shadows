## Обстановка

Виктор дал тестовое задание: найти на «сервере» три спрятанных файла. Сервер — это
каталог `artifacts/test_environment` (симуляция; учебные данные лежат в
[`../data/`](../data/)). Ты подключился и не знаешь о нём ничего: ни где стоишь, ни
что вокруг.

LILITH не даёт приступить к поиску, пока ты не ответишь на первый вопрос —
**где ты находишься**. Она права: на чужой машине это первое, что выясняют.
Всё остальное — поиск, чтение, удаление — делается уже с этого знания.

## Приказ

Собрать `whereami.sh` — инструмент ориентации, который одним запуском отвечает:
где я сейчас, где мой дом, стою ли я в корне системы.

Это первый инструмент твоего `shadow_toolkit` (см. [`../../PROJECTS.md`](../../PROJECTS.md)).
Он маленький, и в этом смысл: повторяемое действие оформляется командой, а не
привычкой каждый раз набирать три строки.

## Данные

| Что | Источник | Значение |
|---|---|---|
| текущий каталог | `pwd` | абсолютный путь, начинается с `/` |
| домашний каталог | `$HOME` | путь вида `/home/<user>` |
| признак корня | сравнение | текущий каталог равен `/` или нет |

Ключевое свойство: `pwd` печатает **абсолютный** путь. Он однозначен из любой точки
дерева — в отличие от относительного, который зависит от того, где ты стоишь.

## Критерии приёмки

- [ ] Файл `whereami.sh` создан в корне серии, начинается с shebang (`#!/usr/bin/env bash`).
- [ ] Проходит `bash -n` — синтаксис без ошибок.
- [ ] Печатает текущий каталог, полученный **через `pwd`**, а не записанный строкой.
- [ ] Печатает домашний каталог (`$HOME`).
- [ ] Сообщает, находишься ли ты в корне `/`.
- [ ] Запуск из разных каталогов даёт **разный** вывод (путь не захардкожен).
- [ ] `bash tests/test.sh` → 6 passed, 0 failed.

## Требования среды

| Требование | Значение |
|---|---|
| root / sudo | не нужен |
| ОС | любая с bash (Linux / macOS / WSL) |
| Сеть | не нужна |
| systemd / Docker / k8s | не нужны |
| Внешние пакеты | нет (только coreutils: `pwd`, `echo`, `grep`) |
| Изоляция теста | фикстура во временном `TEST_ROOT` (`mktemp`), удаляется автоматически |

Проверка **воспроизводима**: тест создаёт временный каталог, запускает твой скрипт
внутри него и сверяет поведение. Твой хост не затрагивается.

## Выполнение

```bash
cp starter/whereami.sh ./whereami.sh
# заменить TODO своим кодом
bash tests/test.sh
```

Застрял — спроси LILITH в чате Cursor. Она объяснит, но не решит за тебя: в этом весь смысл.
Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина | Что делать |
|---|---|---|
| `FAIL: в выводе нет текущего пути` | путь записан строкой, а не получен командой | подставить `$(pwd)` |
| `FAIL: путь захардкожен` | вывод не меняется при запуске из другого каталога | то же: значение должно вычисляться при запуске |
| `bash: ./whereami.sh: Permission denied` | нет бита `x` | `chmod +x whereami.sh` либо запускать `bash whereami.sh` |
| `unbound variable` | `set -u` и обращение к незаданной переменной | инициализировать переменную или задать значение по умолчанию |

## После выполнения

Если скрипт печатает три строки и тест зелёный — ты умеешь ориентироваться и получил
первый инструмент. Дальше LILITH спросит, что **вокруг** тебя: сам каталог ты
видишь, а его содержимое — ещё нет.

Если тест ругается, что путь захардкожен, — скрипт врёт. Он печатает то, что было
верно в момент написания, и будет повторять это на любой машине. Инструмент, который
уверенно сообщает неправду, хуже отсутствующего: ему верят.
