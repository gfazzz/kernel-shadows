## Обстановка

В 10:52 UTC пришёл бюллетень: удалённое выполнение кода без аутентификации в
модуле загрузки. Условие срабатывания — сочетание трёх признаков, все три
описаны. Исправления нет, обещают через три дня.

Предложение в канале — выключить загрузку целиком. Это три с половиной тысячи
законных запросов в сутки, то есть сервис, за который платят, и ровно тот
результат, которого с восьми утра добивается атакующий.

## Приказ

Написать `artifacts/zeroday-mitigation.conf` — фрагмент конфигурации nginx,
подключаемый в `server`-блок до общего `location /`. Мера обязана закрыть
условие срабатывания и не задеть законную работу.

```bash
cp starter/zeroday-mitigation.conf artifacts/
$EDITOR artifacts/zeroday-mitigation.conf
bash tests/test.sh
```

## Чем добывать

Формул в каркасе нет, есть форма. Директивы, которых достаточно для этой
задачи:

| Что нужно | Чем |
|---|---|
| адресовать ровно один путь | `location = /путь { ... }` |
| ограничить размер тела | `client_max_body_size 512k;` |
| проверить заголовок | `if ($http_transfer_encoding ~* chunked) { return 403; }` |
| разрешить только нужный метод | `limit_except POST { deny all; }` |
| видеть срабатывания | `access_log /var/log/nginx/<файл> combined;` |
| передать прошедшее дальше | `proxy_pass http://aurora_backend;` |

Порог из бюллетеня и самая крупная законная загрузка из корпуса — два числа,
между которыми стоит предел. Найди оба, прежде чем писать значение.

## Критерии приёмки

- [ ] Есть заголовок меры: `advisory:`, `expires:` (номер дня операции), `remove-when:`.
- [ ] Срок в будущем и не дальше четырёх обещанных сроков патча.
- [ ] Условие снятия — проверяемое состояние, а не «когда выйдет патч».
- [ ] Закрыты **оба** признака из бюллетеня: размер тела и кодировка.
- [ ] Предел тела не выше порога бюллетеня и не ниже законной загрузки.
- [ ] Совпадение отклоняется явным кодом, срабатывания пишутся в отдельный журнал.
- [ ] Путь не выключен целиком: `deny all` допустим только внутри `limit_except`.
- [ ] Мера не опирается на `User-Agent` и не переопределяет общий `location /`.
- [ ] Прогон корпуса: 14 попыток из 14 отклонены, 0 законных запросов потеряно.
- [ ] `bash tests/test.sh` → 26 passed, 0 failed.

## Требования среды

| Требование | Значение |
|---|---|
| root / sudo | не нужен |
| ОС | любая с bash + awk + grep |
| Сеть | не нужна |
| nginx | **не нужен** — фрагмент проверяется как текст |
| Внешние пакеты | нет |
| Изоляция теста | снимки только читаются |

Прогон корпуса — упрощённая модель: тест извлекает из фрагмента предел тела,
проверку кодировки и ограничение метода и применяет их к каждой строке
корпуса. Полного nginx здесь нет и не требуется — проверяется решение, а не
реализация сервера.

Отдельно проверяется, что данные не выродились: попыток эксплуатации в
корпусе не меньше пяти, законных запросов к тому же пути — тоже (иначе
«запретить путь» было бы верным ответом), и самая крупная законная загрузка
меньше порога бюллетеня.

## Диагностика

| Симптом | Причина | Что делать |
|---|---|---|
| «прошло N попыток» | закрыт один признак из двух | в бюллетене их два |
| «заблокировано N законных» | предел тела ниже законной загрузки | посмотреть максимум по корпусу |
| «deny all вне limit_except» | путь выключен целиком | ограничить метод, а не путь |
| «нет строки expires» | заголовок принят за оформление | это часть меры |
| «срок уже прошёл» | указан день раньше 57-го | сегодня 57-й день операции |
| «нет блока location = …» | использован префиксный `location /api` | нужно точное совпадение |
| «нет proxy_pass» | блок перехватил путь и никуда не отдал | прошедшее идёт в приложение |
| «скобки не сбалансированы» | правка вслепую | посчитать `{` и `}` |

## После выполнения

Зелёный тест означает, что уязвимость закрыта, сервис работает, а мера
найдётся и снимется, когда придёт патч.

Главное, что стоит унести: **у фильтра две ошибки, и они независимы.**
Пропустить атаку и заблокировать своих — разные величины, обе измеримые, и
обе надо посмотреть. Мера, у которой измерена только первая, ломает работу
молча.

И второе: **мера без условия снятия остаётся навсегда.** Не потому, что о ней
забывают, — потому что снимать её невыгодно ни одному конкретному человеку.
Три строки в самом файле — единственное, что этому противостоит.

## Кумулятивность

Ограничение прав процесса как вторая линия — [`s03e05`](../../season-03-system-administration/s03e05-systemd-service/)
(песочница systemd) и [`s07e11`](../../season-07-production-advanced/s07e11-selinux/)
(обязательный контроль доступа). Виртуальный патч не мешает эксплуатации —
он мешает ей начаться; те две меры не мешают ей начаться, но мешают развиться.

Проверка правила на корпусе вместо проверки на глаз — тот же приём, что в
[`s07e06`](../../season-07-production-advanced/s07e06-alert-rules/): условие,
не прогнанное по данным, ничего не гарантирует.

Точность вместо ширины — прямое продолжение [`s08e03`](../s08e03-blackhole/),
где отдавали ровно то, что решено отдать, и [`s05e11`](../../season-05-security-pentesting/s05e11-hardening/),
где укрепление считалось по списку, а не по вкусу.

Следы, оставшиеся от попыток, которые прошли **раньше** этой меры, ищутся в
`s08e05`: мера защищает от будущего, а не от того,
что уже случилось.
