## awk — обработка полей

`awk` читает файл построчно и разбивает каждую строку на поля (разделитель по
умолчанию — пробел/таб):

```
185.220.101.47 - - [04/Oct/2025:03:47:23] "GET /admin HTTP/1.1" 404 0
   $1              $2 $3   $4               $5    $6      $7      $9 ...
```

- `$1` — первое поле, `$0` — вся строка, `$NF` — последнее поле, `NF` — число полей.

```bash
awk '{print $1}' access.log        # IP (первое поле)
awk '{print $1, $9}' access.log    # IP и HTTP-статус
awk '{print $NF}' access.log       # последнее поле
awk -F',' '{print $4}' users.csv   # -F: свой разделитель (CSV)
awk -F':' '{print $1}' /etc/passwd # логины из passwd
```

**Условия в awk** (пригодятся дальше):

```bash
awk '$9 == 404 {print $1}' access.log   # IP только для строк со статусом 404
awk 'NR<=5' access.log                    # первые 5 строк
```

## sort — сортировка

| Флаг | Действие |
|------|----------|
| `-n` | числовая (иначе 100 < 20 лексикографически!) |
| `-r` | обратный порядок |
| `-u` | только уникальные |
| `-k N` | по N-му полю |
| `-t 'X'` | разделитель полей |

> Классическая ошибка: забыть `-n` — и `100` встанет перед `20`, потому что `sort`
> сравнивает как строки.

## uniq — подсчёт повторов

`uniq` убирает **только соседние** дубликаты → перед ним **обязательно `sort`**.

| Флаг | Действие |
|------|----------|
| `-c` | приписать количество повторов |
| `-d` | только дубликаты |
| `-u` | только неповторяющиеся |

## Золотой идиом анализа логов

```bash
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head
#   вытащить IP      группировать  посчитать  ранжировать  верхушка
```

Этот конвейер — рабочая лошадка любого сисадмина: топ IP, топ URL, топ статусов —
меняется только поле в `awk` и, при желании, фильтр `grep` в начале.
