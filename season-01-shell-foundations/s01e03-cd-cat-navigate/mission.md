## Обстановка

Все три файла найдены, но не прочитаны. Имена дают только гипотезу о содержимом:
`.secret_location` может оказаться и координатами, и пустышкой.

Два источника из трёх скрыты, один лежит уровнем ниже — в `documents/`. Чтобы
собрать разведданные, нужно пройти по дереву и открыть каждый.

## Приказ

Извлечь из трёх файлов факты и сдать отчёт `intel.txt`:
допуск оператора, координаты и время встречи, параметры доступа к следующему узлу.

Скрипт не нужен. Результат серии — добытые сведения, а не код.

## Данные

| Поле отчёта | Источник | Что искать |
|---|---|---|
| `clearance_level` | `documents/briefing.txt` | строка `CLEARANCE`, только номер уровня |
| `latitude` | `documents/.secret_location` | строка `Latitude`, значение как в файле |
| `longitude` | `documents/.secret_location` | строка `Longitude` |
| `meeting_time` | `documents/.secret_location` | строка `Time`, формат `ЧЧ:ММ` |
| `next_ip` | `.next_server` | строка `IP Address` |
| `next_port` | `.next_server` | строка `Port` |
| `next_user` | `.next_server` | строка `Username` |

Значения переписываются **точно как в источнике**, включая символы вроде `°N`.

## Критерии приёмки

- [ ] Отчёт создан в рабочей папке: `artifacts/intel.txt`.
- [ ] Все семь полей заполнены.
- [ ] Значения совпадают с источниками посимвольно (тест извлекает их заново).
- [ ] Скрытые файлы прочитаны — они читаются как обычные.
- [ ] `bash tests/test.sh` → 9 passed, 0 failed.

## Диагностика

| Симптом | Причина | Что делать |
|---|---|---|
| `не заполнено` | поле пустое | вписать значение справа от `=` |
| `указано '55.7558 N', в источнике '55.7558°N'` | символ потерян при переписывании | копировать значение как есть |
| `cat: documents/.secret_location: No such file` | ты не в каталоге «сервера» | `cd ../data/test_environment` либо полный путь |
| `meeting_time` не совпало | взято лишнее (`14:00 MSK`) | только `ЧЧ:ММ` |
| файл «пустой» на экране | открыт не тот путь | проверить `pwd` и `ls -A` |

## После выполнения

Если тест зелёный — у тебя есть то, зачем Виктор давал сутки: точка встречи с
временем и окном прибытия, опознавательный знак и доступ к следующей машине.

Если значения не сходятся — не подгоняй их под ожидание. Расхождение обычно
означает, что прочитан не тот файл или значение переписано «примерно». Разведданные,
подогнанные под ожидание, приводят не туда, куда нужно, — и выясняется это на месте.
