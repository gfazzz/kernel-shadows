# MISSION s02e01 — «Твой адрес в сети»

**Тип:** `Type A` — Bash Automation
**Концепт:** IPv4-адресация (класс, private/public, спец-адреса) + модель TCP/IP
**Оценка времени:** ~50 минут

---

## Задача

В ЦОД «Москва-1» сотни адресов. Прежде чем разбираться, кто есть кто в сети, нужен
инструмент, который по IP скажет главное: валиден ли он, какого класса и виден ли из
интернета. Собери `ipinfo.sh`.

**Артефакт:** `ipinfo.sh` (в artifacts/). Принимает адрес аргументом:
`./ipinfo.sh 10.50.1.100`.

```bash
cp starter/ipinfo.sh artifacts/ipinfo.sh
# отредактируй TODO, затем:
bash tests/test.sh
```

---

## Критерии приёмки

`bash tests/test.sh` зелёный (11 проверок). Ключевое:

1. Корректный bash-скрипт с shebang.
2. **Валидация**: ровно 4 октета, каждый 0-255; иначе — stderr + ненулевой exit
   (`999.1.1.1`, `1.2.3` отвергаются).
3. **Класс** по первому октету (A `<128`, B `<192`, C `<224`).
4. **Тип**: loopback (`127.*`), private (10/8, 172.16-31, 192.168), broadcast, public.
   Граница важна: `172.16-31` — private, а `172.32` — уже public.
