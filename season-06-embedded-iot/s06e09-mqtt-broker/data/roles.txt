# выдавать нельзя: права выдаются по потребности, а не «на всякий случай».
#
# Формат: имя_роли  вид  что_нужно
#   вид: pattern — правило общее для всех клиентов этого вида, имя
#        пользователя подставляется в тему (%u); user — конкретный клиент
node       pattern  писать свою телеметрию, читать свои команды
dashboard  user     читать телеметрию всех, писать команды всем
recorder   user     читать телеметрию всех, больше ничего
monitor    user     читать служебные темы брокера ($SYS)
