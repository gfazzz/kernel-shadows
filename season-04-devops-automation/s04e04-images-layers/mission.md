## Объект разведки

| Раздел | Что это |
|---|---|
| `=== docker images ===` | что лежит на сборочной машине |
| `=== docker history ops/collector:1.4.0 ===` | слои, сверху вниз |
| `=== docker inspect … ===` | метаданные: `User`, `Env`, `Cmd` |
| `=== базовый образ по Dockerfile ===` | строка `FROM` |
| `=== trivy image … ===` | сводка сканера по образу и по двум базам |

Всё в одном файле: [`data/docker_ops_snapshot.txt`](../data/docker_ops_snapshot.txt).

## Чем добывать

| Что нужно | Как |
|---|---|
| вырезать раздел | `awk -v s='docker images' '$0=="=== "s" ===" {f=1; next} /^=== /{f=0} f' "$D"` |
| разных образов | по колонке `IMAGE ID`, `sort -u` |
| самый крупный | сравнить размеры, приведя `GB`/`MB` к одному виду |
| слои | строки `docker history` после заголовка |
| слои базы | помечены `#(nop)` — их писали не ты |
| переменные окружения | массив `Env` в `inspect` |
| от кого работает | поле `User`; пустая строка — это **не** «никто» |
| уязвимости | строки `Total:` в сводке сканера |

## Требования среды

| Требование | Значение |
|---|---|
| root / sudo | не нужен |
| ОС | любая с bash + awk + coreutils |
| Сеть | не нужна |
| `docker` | **не нужен** — разбирается копия вывода команд |
| Внешние пакеты | нет |
| Изоляция теста | эталон вычисляется из того же снимка, констант в тесте нет |

Тест дополнительно проверяет, что ловушки на месте: два тега на один
`IMAGE ID`, пара «скопировали — удалили» с нулевым слоем удаления и пустое
поле `User`.

## Выполнение

```bash
cd season-04-devops-automation/s04e04-images-layers
cp starter/image_report.txt artifacts/image_report.txt
D=../data/docker_ops_snapshot.txt
awk -v s='docker history ops/collector:1.4.0' '$0=="=== "s" ===" {f=1; next} /^=== /{f=0} f' $D
bash tests/test.sh
```

Если docker есть на твоей машине, стоит посмотреть на любой свой образ:

```bash
docker history $(docker images -q | head -1)
docker system df
```

## Диагностика

| Симптом | Причина | Что делать |
|---|---|---|
| образов на один больше | посчитаны строки | считать по `IMAGE ID` |
| крупнейший слой 149MB | взят слой базы | строки с `#(nop)` не в счёт |
| «освободило ли удаление место» = yes | принято на веру | слой удаления весит `0B`, слой копирования остался |
| `effective_user` пустой | скопировано поле как есть | пустое поле — это root |
| размер не принят | пересчитан в другие единицы | писать как напечатано: `1.01GB` |
| не найдена переменная с секретом | смотрели только `history` | массив `Env` в `inspect` |
