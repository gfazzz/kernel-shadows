## Чему ты научишься

- `xargs`: превращать строки в аргументы и ставить пакеты одной транзакцией вместо N.
- Тому, что делает отчёт отчётом: дата, архитектура, точные версии, честный итог `N / M`.
- Идемпотентности — почему повторный запуск обязан быть безопасным.
- Метанавыку сезона: **инструменты вместо действий**. Повторяемое действие оформляется командой, а не привычкой.

Подробнее, с историей и подводными камнями, — в [`theory.md`](theory.md).

## Теория: список как аргументы

### `xargs` — превратить строки в аргументы

Некоторые команды читают stdin (`grep`, `sort`, `wc`), а некоторые — нет: `apt install` ждёт имена пакетов **аргументами**. `xargs` мостит эту разницу — читает строки со входа и подставляет их как аргументы:

```bash
grep -v '^#' tools.txt | awk '{print $1}' | xargs sudo apt install -y
#   убрать комментарии   взять имя пакета   один вызов на весь список
```

Разница с циклом не косметическая. `while read p; do apt install "$p"; done` вызывает `apt` по разу на пакет: каждый раз заново строится граф зависимостей, каждый раз блокируется и разблокируется база `dpkg`, каждый раз возможен свой сбой на середине. Один `apt install pkg1 pkg2 pkg3` строит **один** план и выполняет его целиком.

Полезные флаги:

```bash
xargs -n 1 команда        # по одному аргументу за вызов
xargs -I {} команда {}.bak # подставить в шаблон
xargs -r команда           # не запускать на пустом входе (GNU) — важно!
xargs -0 команда           # разделитель NUL, в паре с find -print0
```

Флаг `-r` стоит помнить отдельно: без него `xargs` на пустом входе всё равно запустит команду без аргументов, и `apt install` без пакетов — ещё безобидный случай, а `rm` без аргументов бывает не таким.

### Отчёт о состоянии

Тело отчёта — уже знакомые инструменты. Статус берётся у `dpkg`, версия — третьим полем его вывода:

```bash
dpkg -l "$pkg" | grep -q '^ii'                     # установлен?
dpkg -l "$pkg" | awk '/^ii/{print $3; exit}'       # версия
```

`exit` после `print` не украшение: без него `awk` продолжит читать вывод и на многострочном ответе напечатает несколько версий.

> **LILITH:** *«Отчёт полезен ровно настолько, насколько его можно перечитать через месяц. Дата, архитектура, версии — это не бюрократия, это то, что позволит понять, почему на одной машине всё работает, а на другой нет.»*

## Проверка: LILITH задаёт вопросы

**LILITH:** *«Почему `xargs apt install` лучше цикла с `apt install` внутри?»*

<details>
<summary>Подумай 30 секунд</summary>

Потому что `apt` — не команда «поставь файл», а планировщик. За один вызов он строит общий граф зависимостей для всех запрошенных пакетов, разрешает конфликты между ними и скачивает всё нужное одним заходом.

Цикл превращает одну транзакцию в N независимых: медленнее, шумнее и, главное, с промежуточными состояниями — если сбой случится на седьмом пакете, система останется в положении «шесть поставлено, пять нет».
</details>

**LILITH:** *«В отчёте пакет показал `rc`. Считать его установленным?»*

<details>
<summary>Ответ</summary>

Нет: `rc` — это удалённый пакет, от которого остались только конфигурационные файлы. Установлен исключительно `ii`.

Здесь это уже не абстракция, а прямая порча отчёта: пакет с `rc` попадёт в графу «установлено», отчёт покажет готовность, а на машине не окажется программы. И заметят это в тот момент, когда она понадобится.
</details>

<details>
<summary>Подсказка (если застрял на 5+ минут)</summary>

```bash
if dpkg -l "$pkg" 2>/dev/null | grep -q '^ii'; then
    ver=$(dpkg -l "$pkg" 2>/dev/null | awk '/^ii/{print $3; exit}')
    echo "  ✓ $pkg ($ver)"

fi
```

</details>

## Разбор типичных ошибок

**Собрать отчёт в подоболочке.** `( … ) > "$report"` выглядит так же, но счётчики, посчитанные внутри, снаружи будут нулевыми — та же ловушка, что с `cat | while` в s01e08, только в другом обличье. Нужны фигурные скобки.

**Печатать версию без `exit` в `awk`.** На пакете, чей вывод занимает несколько строк, `/^ii/{print $3}` напечатает их все, и в отчёт попадёт «версия» вида `2.34.1-1 1.6-2`. Строка выглядит почти правдоподобно — именно поэтому её не замечают.

**Считать готовность по количеству строк.** Соблазн написать «Установлено: 5 / 5», посчитав строки манифеста, а не результаты проверок, велик и обычно возникает под конец. Отчёт о готовности, который считает сам себя, — это не отчёт.
