# MISSION s02e08 — «Ключи вместо паролей»

**Тип:** `Type A` — Bash Automation
**Концепт:** SSH-ключи — права приватного ключа (600) и тип (ed25519)
**Оценка времени:** ~50 минут

---

## Задача

Крылов читает трафик (DPI). Пароли — слабое звено. Команда переходит на SSH-ключи, но
ключ с неправильными правами SSH просто откажется использовать. Собери `ssh_key_check.sh`:
проверяет приватные ключи в каталоге на права (600/400) и тип (ed25519 предпочтителен).

**Артефакт:** `ssh_key_check.sh` (в artifacts/).
Использование: `./ssh_key_check.sh ~/.ssh`.

```bash
cp starter/ssh_key_check.sh artifacts/ssh_key_check.sh
# отредактируй TODO, затем:
bash tests/test.sh
```

---

## Критерии приёмки

`bash tests/test.sh` зелёный (9 проверок). Ключевое:

1. Корректный bash-скрипт с shebang.
2. Проверяет права приватного ключа: `600`/`400` — ок, иначе — флаг.
3. Публичные ключи (`*.pub`) пропускает.
4. Тип по имени: `id_ed25519` (ок), `id_rsa` (ок), `id_dsa` (устарел → флаг).
5. Считает ключи и проблемы; несуществующий каталог → ненулевой exit.
