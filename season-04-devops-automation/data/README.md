# data/ — учебные данные Season 4

В отличие от прошлых сезонов, здесь не только снимки: часть данных
**восстанавливается скриптом**, потому что объект изучения — репозиторий,
а не текстовый файл.

## Что где

| Файл | Для серий | Что это |
|------|-----------|---------|
| `build_shadow_iac.sh` | s04e01–s04e03 | сборщик учебного репозитория `shadow_iac`: 12 коммитов, две ветки, слияние и попавший в историю пароль. Даты и авторы зафиксированы, поэтому репозиторий получается побитово одинаковым при каждом запуске — включая хеши коммитов. |

## Как пользоваться

```bash
cd season-04-devops-automation
bash data/build_shadow_iac.sh /tmp/shadow_iac
cd /tmp/shadow_iac
git log --oneline --graph --all
```

Пересобрать можно сколько угодно раз: удалите каталог и запустите снова.
Скрипт ничего не скачивает — всё содержимое коммитов записано в нём самом.

> Сборщик намеренно повторяет типичную историю небольшой команды: работа в
> ветке, слияние, забытый `.env` и запоздалая попытка «просто удалить файл».
