# Снимок состояния LVM на shadow-server-01

#
# Команды:
#   pvs ; vgs ; lvs ; lsblk -dn -o NAME,SIZE,TYPE
#
# Три уровня LVM:
#   PV (physical volume)  — физический носитель, размеченный под LVM
#   VG (volume group)     — общий котёл из нескольких PV
#   LV (logical volume)   — том, нарезанный из котла; на нём файловая система
#
# Место для нового тома берётся из VG. Если VFree равен нулю, сначала надо
# добавить в группу ещё один PV — сам по себе подключённый диск ей не виден.
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
