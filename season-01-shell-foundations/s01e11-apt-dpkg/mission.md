# MISSION s01e11 — «Что уже стоит?»

**Тип:** `Type B` — Linux Tools (используем `apt`/`dpkg`, а не пишем обёртки)
**Концепт:** управление пакетами — `apt` (установка/поиск) + `dpkg` (проверка статуса)
**Оценка времени:** ~50 минут

---

## Задача

Виктор прислал список инструментов операции. Прежде чем ставить недостающее, надо
понять, **что уже установлено**. Собери `pkg_check.sh`: читает список пакетов и через
`dpkg` помечает каждый как установленный/отсутствующий, выводит итог.

**Артефакт:** `pkg_check.sh` (в artifacts/).
Использование: `./pkg_check.sh required_tools.txt`.

```bash
cp starter/pkg_check.sh artifacts/pkg_check.sh
# отредактируй TODO, затем:
bash tests/test.sh
```

> **Type B напоминание:** реальная установка — это `sudo apt install <pkg>` напрямую.
> Мы **не** пишем bash-обёртку над apt; скрипт лишь читает список и сверяет статус.

---

## Критерии приёмки

`bash tests/test.sh` зелёный (9 проверок). Ключевое:

1. Корректный bash-скрипт с shebang.
2. Проверяет статус через `dpkg -l "$pkg" | grep '^ii'`.
3. Классифицирует верно: `git/curl/jq` — установлены, `htop/tree` — нет.
4. Итог: `Установлено: 3 | Отсутствует: 2`.
5. Пропускает комментарии/пустые; отсутствующий файл → ненулевой exit.

> Тест **подменяет `dpkg`** мок-версией — ни root, ни apt, ни Ubuntu не нужны.

---

## Требования среды

| Требование | Значение |
|------------|----------|
| root / sudo | не нужен (для теста; реальная установка — с `sudo`) |
| ОС | любая с bash (тест мокает `dpkg`) |
| Сеть | не нужна |
| systemd / Docker | не нужны |
| Внешние пакеты | в реальном запуске — `dpkg`; в тесте подменяется |
| Изоляция теста | мок-`dpkg` в `PATH` + фикстура-манифест во временном `TEST_ROOT` |
