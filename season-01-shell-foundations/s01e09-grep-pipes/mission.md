## Задача

Анна прислала `access.log` с ночной атаки — тысячи строк. Руками не прочитать.
Собери `filter_attack.sh`: выделяет подозрительные запросы (HTTP-статус **не 200**)
и считает их через конвейер.

**Артефакт:** `filter_attack.sh` (в artifacts/). Принимает лог аргументом:
`./filter_attack.sh access.log`.

```bash
cp starter/filter_attack.sh artifacts/filter_attack.sh
# отредактируй TODO, затем:
bash tests/test.sh
```

---

## Критерии приёмки

`bash tests/test.sh` зелёный (7 проверок). Ключевое:

1. Корректный bash-скрипт с shebang.
2. Выводит **только** не-200 строки (реально фильтрует: нормальные 200-запросы не просачиваются).
3. Считает подозрительные через конвейер `grep … | wc -l`.
4. Отсутствующий файл → сообщение в stderr и ненулевой exit.
