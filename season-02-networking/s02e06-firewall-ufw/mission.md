# MISSION s02e06 — «Читаем стену»

**Тип:** `Type B` — Linux Tools (`ufw`/`iptables`, читаем правила)
**Концепт:** firewall — правила ufw, политика по умолчанию, опасные ALLOW
**Оценка времени:** ~50 минут

---

## Задача

Идёт DDoS, и первое — понять текущую «стену»: что вообще открыто. Собери `fw_audit.sh`:
читает вывод `ufw status` и помечает опасные правила — чувствительные порты (БД/кэши),
торчащие в интернет (`Anywhere`).

**Артефакт:** `fw_audit.sh` (в корне серии).
Использование: `./fw_audit.sh ufw_status.txt`.

```bash
cp starter/fw_audit.sh ./fw_audit.sh
# отредактируй TODO, затем:
bash tests/test.sh
```

> Реальный `ufw` меняет правила ядра и требует root. Здесь **читаем** правила из файла
> (`ufw status > file`) — аудит безопасен и воспроизводим.

---

## Критерии приёмки

`bash tests/test.sh` зелёный (8 проверок). Ключевое:

1. Корректный bash-скрипт с shebang.
2. Разбирает строки `ufw status`, берёт порт (первое поле, без `/tcp`).
3. Флагует чувствительный порт (3306/6379/5432/…), открытый на `Anywhere`.
4. Порт на `127.0.0.1` **не** флагуется; считает число проблем.
5. Отсутствующий файл → ненулевой exit.
