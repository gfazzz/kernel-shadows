## [1.0.0] — 30 августа 2026

Первый релиз. До него курс существовал только как черновик: публичной версии
не было, а внутренняя нумерация успела обзавестись тремя параллельными
схемами сразу (`v0.4.5.x` в сезонных README, `v1.0.5.x` в коммитах,
`v0.5.0`–`v0.8.0` в релизах) плюс рабочим именем «2.0» у пересборки. Ни одна
из них наружу не выходила, поэтому первый публичный тег — `v1.0.0`.

Черновики остались в истории: ветка `archive/main-pre-v2.0` — состояние до
пересборки (32 монолитных эпизода), ветка `v2.0-refactor` — ход самой
пересборки. Таблица соответствия старых путей новым — ниже.

### Что это

101 серия в восьми сезонах, 98 ч 25 мин чистого времени на задачи,
2335 автоматических проверок. Единица курса — серия: один концепт, одна
задача, один проверяемый артефакт, 45–90 минут.

| | |
|---|---|
| Серий | 101 в 8 сезонах |
| Автоматических проверок | 2335, все зелёные |
| Чистого времени на задачи | 98 ч 25 мин (измерено обходом шапок) |
| Требует root, сети или железа | ни один тест |
| Прогон одной командой | `make check` |

### Устройство курса

- **Атомарные серии** `sNNeMM`: `README.md` + `mission.md` + `theory.md` +
  `starter/` + `solution/` + `tests/` + `artifacts/`.
- **Четыре типа серий** — A (Automation), B (Configuration), C (Investigation),
  D (Code). Баланс типов — часть критериев приёмки сезона: 25 / 38 / 30 / 8.
  Скрипты составляют четверть курса, а не его содержание.
- **Сквозные артефакты сезонов**: `shadow_toolkit`, `netshield`, `fleet_admin`,
  `shadow_iac`, `hardening_kit`, `shadow_mesh`, `aurora`, `shadow_core`.
  Финал `s08e12` — приёмка из двенадцати фаз, по одной на навык сезона.
- **Прогрессивная автономия**: S1–S3 полный каркас и эталон, S4–S5 каркас,
  S6–S7 интерфейсы, S8 только договор вызова.
- **Воспроизводимость**: `make test-repeat` (два прогона подряд),
  `make test-locale` (чужая локаль и часовой пояс), `make clean-clone`
  (приёмка на чистом клоне), CI с матрицей по сезонам.
- **Генераторы документации**: `tools/gen_index.sh` (указатель серий),
  `tools/gen_bibliography.sh` (358 источников из `theory.md`),
  `tools/gen_timeline.sh` (хронология и проверка логистики),
  `tools/season_table.py` (таблицы серий в README сезонов).

### Приведение к общему виду с OPERATION MOONLIGHT

Курсы — одна вселенная и должны читаться одинаково. К релизу 1.0.0 оба
приведены к общему канону:

- **Единое обращение на «ты».** Было вперемешку: серии на «ты», корневой
  README и `GETTING_STARTED` на «вы» — 473 строки в 161 файле. Речь
  персонажей сохранена как была; голос LILITH переведён на «ты», как у LUNA.
- **Единая структура серии**: шапка-кодблок · Previously · сцена ·
  Чему ты научишься · Теория · Проверка · Задание · Разбор типичных ошибок ·
  Debriefing · Ссылки и AI-usage · Навигация.
- **«Чему ты научишься»** — 101 новый раздел, по четыре пункта, последний
  всегда метанавык.
- **Сквозная навигация**: конец сезона ведёт в начало следующего, а не в тупик.
- **Сезонные README** переписаны по форме MOONLIGHT: 118–149 строк вместо
  298–601, одна структура на все восемь.

### Убрано из main

- Отсылки к монолитной нумерации `Episode NN` — 90 в шапках серий и 44 в
  тексте; «(ч. 1)» без номера эпизода; римские цифры в заголовках.
- Восемнадцать плашек «Серия в работе: Season N пересобирается по плану v2.0»
  в сериях, которые давно существуют.
- Разделы «🆕 v2.0: атомарные серии» в сезонных README — они объявляли
  рефакторинг вместо того, чтобы описывать сезон.
- `docs/PROJECTS.md` был планом («ввести то, чего у курса сейчас нет») —
  стал описанием того, что есть.

## До 1.0.0 — история черновиков

Публичных релизов не было; ниже — хроника разработки, чтобы по ней можно было
восстановить, откуда что взялось.

**Пересборка (июль — август 2026), рабочее имя «2.0», ветка `v2.0-refactor`.**
Аудит черновика показал, что отметка «100 % COMPLETE» не соответствовала
фактам: README серий достигали 3620 строк, часть тестов была красной,
многие требовали root и живого хоста, нумерация и версии противоречили друг
другу. 32 монолитных эпизода пересобраны в 101 атомарную серию, введены
типы C и D, тест-харнесс, CI и генераторы документации, закрыт канон сюжета
(Архитектор — Кирилл Соболев, раскрыт в `s08e10`).

**Черновик (октябрь 2025), ветка `archive/main-pre-v2.0`, тег `v0.8.0-archive`.**
32 эпизода `episode-NN`, восемь сезонов, сюжет и теория написаны целиком.
Внешний аудит 4 октября 2025 дал 4.2 из 5: полнота теории 4.5, увлекательность
сюжета 4.7, удобство 3.8, отсутствие несостыковок 3.9. Замечания по последним
двум пунктам и стали причиной пересборки.

**Начало (3 октября 2025).** Идея опубликована на
[Eurecable](https://eurecable.com/ideas/973) как спин-офф
[OPERATION MOONLIGHT](https://github.com/gfazzz/moonlight-course) с новым
героем — Максом Соколовым.
