## Задача

Команде нужен **baseline** сети: кто отвечает, с какой задержкой. Собери капстоун
`net_diag.sh`: по списку хостов пингует каждый, парсит RTT из вывода и выдаёт таблицу
`HOST / STATUS / RTT` + итог. Это объединяет навыки Season 1 (ping/exit code, цикл по
файлу, `sed`) в сетевой аудит.

**Артефакт:** `net_diag.sh` (в корне серии).
Использование: `./net_diag.sh hosts.txt`.

```bash
cp starter/net_diag.sh ./net_diag.sh
# отредактируй TODO, затем:
bash tests/test.sh
```

---

## Критерии приёмки

`bash tests/test.sh` зелёный (8 проверок). Ключевое:

1. Корректный bash-скрипт с shebang.
2. Пингует каждый хост, определяет `UP`/`DOWN` по exit code.
3. Для доступных **парсит RTT** из вывода `ping` (`sed -n 's/.*time=\([0-9.]*\).*/\1/p'`).
4. Итог `UP=N DOWN=M`; комментарии/пустые строки пропускаются.

> Тест **мокает `ping`** (выдаёт `time=12.3 ms`) — ни root, ни сеть не нужны.
