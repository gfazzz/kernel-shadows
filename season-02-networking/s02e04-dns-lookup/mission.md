## Задача

DNS в дата-центре под атакой (cache poisoning). Прежде чем защищать, научись читать:

Использование: `./dns_lookup.sh google.com A` (тип по умолчанию — A).

```bash

# отредактируй TODO, затем:

```

---

## Критерии приёмки

`bash tests/test.sh` зелёный (7 проверок). Ключевое:

1. Корректный bash-скрипт с shebang.
2. Запрос через `dig DOMAIN TYPE +short`; тип по умолчанию — `A`.
3. Выводит значение(я) записи и их количество.
4. Разные типы: `A` (IPv4), `MX` (почта, несколько значений).
5. Нет записи (NXDOMAIN) → сообщение + ненулевой exit.

> Тест **подменяет `dig`** мок-версией с фиксированными ответами — сеть не нужна.

| Требование | Значение |
