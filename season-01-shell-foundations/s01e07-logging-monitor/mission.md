# MISSION s01e07 — «Production-мониторинг» (капстоун ep02)

**Тип:** `Type A` — Bash Automation
**Концепт:** логирование (redirects `>`/`>>`, `date`) + сборка production-скрипта
**Оценка времени:** ~60 минут

---

## Задача

Проверка работает, но результаты исчезают с экрана. Дмитрию нужна **история**.
Собери капстоун `server_monitor.sh`: проходит по списку серверов, пингует каждый,
**логирует** каждую строку с таймстампом в файл, печатает `SUMMARY` и выдаёт
`ALERT`, если есть недоступные.

**Артефакт:** `server_monitor.sh` (в artifacts/).
Использование: `./server_monitor.sh servers.txt monitor.log`.

```bash
cp starter/server_monitor.sh artifacts/server_monitor.sh
# отредактируй TODO, затем:
bash tests/test.sh
```

---

## Критерии приёмки

`bash tests/test.sh` зелёный (9 проверок). Ключевое:

1. Корректный bash-скрипт с shebang.
2. Пишет **лог-файл** с таймстампами формата `YYYY-MM-DD HH:MM:SS` (`date`).
3. `SUMMARY: UP=… DOWN=…` считается верно.
4. При `DOWN > 0` выдаёт `ALERT`.
5. Повторный запуск **дополняет** лог (`>>`), а не затирает (`>`).
6. Без `awk` (его учим в s01e08+).

> Тест мокает `ping` — живая сеть не нужна.
