# MISSION s02e02 — «Что слушает на сервере»

**Тип:** `Type A` — Bash Automation
**Концепт:** порты и сокеты — `ss`, состояние LISTEN, неожиданные порты
**Оценка времени:** ~50 минут

---

## Задача

Крылов ищет открытую дверь. Найди их первым: собери `check_ports.sh`, который
показывает слушающие TCP-порты (через `ss`) и, сверяясь с allowlist, помечает
**неожиданные** порты — потенциальные бэкдоры.

**Артефакт:** `check_ports.sh` (в корне серии).
Использование: `./check_ports.sh allow.txt` (allow.txt — разрешённые порты, по одному на строку).

```bash
cp starter/check_ports.sh ./check_ports.sh
# отредактируй TODO, затем:
bash tests/test.sh
```

---

## Критерии приёмки

`bash tests/test.sh` зелёный (8 проверок). Ключевое:

1. Корректный bash-скрипт с shebang.
2. Извлекает слушающие порты из `ss -tln` (4-я колонка `Local Address:Port`).
3. Номер порта берёт после последнего `:` (работает для `0.0.0.0:22` и `[::]:22`).
4. Сверяет с allowlist: разрешённые — `✓`, остальные — `⚠️ неожиданный`; считает их число.
5. Разрешённый порт не флагуется как неожиданный.

> Тест **подменяет `ss`** мок-версией (порт `4444` — «бэкдор») — ни root, ни сеть не нужны.

---

## Требования среды

| Требование | Значение |
|------------|----------|
| root / sudo | не нужен |
| ОС | любая с bash (тест мокает `ss`) |
| Сеть | **не нужна** |
| systemd / Docker | не нужны |
| Внешние пакеты | в реальном запуске — `ss` (пакет `iproute2`); в тесте подменяется |
| Изоляция теста | мок-`ss` + allowlist во временном `TEST_ROOT` |
