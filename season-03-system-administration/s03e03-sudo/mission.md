## Обстановка

Учётные записи разобраны, права пересчитаны. Осталось объяснить, откуда у
противника был root: строка `%sudo ALL=(ALL:ALL) ALL` из стандартной установки
плюс две подсаженные учётки, добавленные в группу `sudo`. Ничего не взламывали —
воспользовались списком, который никто не перечитывал.

Сервер пересобирают в 09:00. Политику доступа нужно сдать раньше.

## Приказ

Переписать `artifacts/ops-team` — файл, который ляжет в `/etc/sudoers.d/`, — так,
чтобы каждый из команды мог ровно то, что нужно ему по роли, и ничего сверх.


## Чем добывать

| Что нужно | Как |
|---|---|
| набор команд под именем | `Cmnd_Alias NET_DIAG = /usr/sbin/ip, /usr/bin/ss` |
| правило на группу | `%ops-net ALL=(root) NET_DIAG` |
| правило на человека | `max ALL=(ALL:ALL) ALL` |
| ограничить аргументы | `/usr/bin/systemctl restart nginx` |
| запись сессии одного пользователя | `Defaults:max log_input, log_output` |
| проверить синтаксис (на своей машине) | `visudo -c -f artifacts/ops-team` |

Команда указывается **абсолютным путём** — иначе правило не совпадёт никогда.
Побеждает **последнее** совпавшее правило, поэтому широкие строки надо убирать,
а не «перекрывать» узкими.

| Требование | Значение |
|---|---|

## Диагностика

| Симптом | Причина | Что делать |
|---|---|---|
| тест называет чужие имена в правиле на группу | оставлена строка `%sudo` | убрать её целиком, узкие правила её не перекрывают |
| «команда без абсолютного пути» | написано `ip` вместо `/usr/sbin/ip` | sudo сверяет полный путь |
| «правило на несуществующую группу» | опечатка в имени | сверить с `awk -F: '{print $1}' ../data/group_shadow-01.txt` |
| «выходят в root-оболочку» | выдан `vim`, `less`, `find`, `awk` | из них открывается оболочка: `:!sh`, `!sh`, `-exec` |
| `journalctl` не принят | забыт `--no-pager` | без него journalctl сам запускает `less` |
| `systemctl` не принят | выдан без аргументов | перечислить подкоманды и юниты |
| «полного доступа нет ни у кого» | убрано правило `max` | наименьшие привилегии ≠ отсутствие администратора |
| синтаксис не принят | правило без `=` или лишняя строка | формат: `кто хост=(от кого) [теги:] команды` |

## После выполнения

Зелёный тест означает, что политику можно прочитать целиком за минуту и по
каждой строке ответить, кому и зачем. Это и есть результат — не количество
запретов, а возможность проверить список.

Полезно вернуться к `starter/ops-team` и посмотреть на него ещё раз: там нет ни
одной строки, написанной со злым умыслом. Каждая появилась потому, что кому-то
что-то было нужно прямо сейчас.
