# starter — s01e04

Здесь нет файла-заготовки: эта серия выполняется **командами**, а её результат —
состояние файловой системы, а не текст, который надо заполнить.

Рабочее пространство создаётся с нуля в `artifacts/workspace/`. Что именно должно
получиться — в [`../mission.md`](../mission.md), раздел «Приказ» и «Критерии приёмки».

Начни так:

```bash
cd ..                       # в корень серии
mkdir -p artifacts/workspace
cd artifacts/workspace
```

Дальше — по заданию. Если забыл флаг, спроси не у поисковика, а у системы:

```bash
man mkdir
man cp
```

Как читать man-страницы — в [`../README.md`](../README.md), раздел II.
