# Служебные ручки aurora-api — выписка из документации приложения.
#
# Формат: путь, кого спрашивает, что отвечает.
#
# Колонка depends_on важнее остальных: она говорит, ходит ли ручка во внешние
# системы. Ручка, которая ходит, не годится для пробы живости — падение базы
# перезапустит все реплики разом и добавит к аварии ещё одну.
#
# path       depends_on   200_means
/healthz     none         процесс жив, главный цикл не завис
/ready       postgres,mesh-collector   пул базы поднят и таблица маршрутов загружена
/metrics     none         экспозиция метрик Prometheus, формат text/plain

# Обязательные переменные окружения (из README приложения):
#
#   AURORA_DB_DSN   строка подключения к postgres, содержит пароль
#   AURORA_MESH_URL адрес mesh-collector
#   AURORA_LOG_JSON формат журнала
#
# Отсутствие AURORA_DB_DSN — то самое «FATAL config: required key ... is
# missing», из-за которого под dk3np падал в s07e01. DSN содержит пароль,
# поэтому его место — Secret, а не ConfigMap и тем более не значение в
# манифесте: манифест лежит в git.
